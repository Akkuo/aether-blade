# AETHER BLADE — 聖樹傳說

致敬早期《薩爾達傳說》（NES / SNES）風格與玩法的原創 2D 俯視動作冒險遊戲（零相依 HTML5 Canvas + WebGL Bloom + Web Audio 合成器）。

## 線上遊玩
- https://akkuo.github.io/aether-blade/

## 操作方式
- `WASD` / `方向鍵`：四方向移動（推箱機關直接頂住石塊推動）
- `Space` / `Z` / `J`：揮劍 / 與長老或寶箱互動（**滿血揮劍發射劍氣**，**長按蓄力 360° 迴旋斬**）
- `E` / `X`：使用道具（**疾風迴力鏢** / **炸彈**）
- `Q`：切換道具
- `Shift`：翻滾閃避（短暫無敵）
- `G`：開關 WebGL Bloom 後處理
- `M`：靜音
- `R`：重新開始
